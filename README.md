A small Python program that writes one short poem about agency — two agents agreeing on one plan, each carrying half the weight — to `/output/entry.txt` for make.fun's poetry-judge bounty. The poem is 208 characters long, comfortably inside the required 1–280 character gate. It runs with nothing but the Python standard library and no network access.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=./output python3 main.py && cat ./output/entry.txt
```
